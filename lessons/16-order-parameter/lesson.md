## 一根旋鈕，兩個世界

畫面上是最素的群體模型：**每個粒子只做一件事**——看看半徑內的鄰居都往哪走，取平均，自己也往那走，然後手抖一下。

沒有分離、沒有聚合、沒有避碰。只有「跟著平均走」加「手抖」。抖的幅度就是 `eta`。

現在慢慢把 `eta` 往右轉。你會期待整群慢慢變亂——**但它不是慢慢的。**

<button class="try" data-preset='{"eta":0.4}'>eta = 0.4</button>　<button class="try" data-preset='{"eta":2.2}'>eta = 2.2</button>　<button class="try" data-preset='{"eta":3.4}'>eta = 3.4</button>

在某個位置，整群「啪」一下就散了。這件事有名字：**相變（phase transition，物質狀態的突然改變）**。跟水到 0 度結冰是同一類事情。

## 把「整不整齊」變成一個數字

眼睛看得出整不整齊，但眼睛沒辦法比較。所以要有一個數字。

**秩序參數 va**：把每個粒子的行進方向當成一支長度為 1 的箭頭，全部加起來，除以粒子數，取長度。

- 全部同方向 → 箭頭疊加 → **va = 1**
- 方向亂七八糟 → 互相抵消 → **va ≈ 0**

畫面下面那張折線圖畫的就是它。粒子的顏色也是方向——**同顏色 = 同方向**，所以有秩序的時候整片是同一個色，沒秩序的時候像打翻的顏料。

這個「把一整群的狀態壓成一個數字」的動作，是整個統計物理的核心手法。你在第 11 課看過同步度、第 13 課看過偏離真值——**都是同一件事的不同版本。**

## 那條陡降的曲線

按面板上的 **「▶ 掃描雜訊 0 → 最大」**。程式會自動把 `eta` 從 0 慢慢加上去，每個值等它穩定，把 (eta, va) 點出來。

跑完你會看到一條曲線：前段是平的高原，接著**一個陡降**，然後貼地。

那個陡降的位置就是**臨界點**。原論文在密度 ρ = 0.4 的條件下量到 **η꜀ = 2.9 ± 0.05**（滿格是 2π ≈ 6.28，那是完全隨機）。他們還量到秩序參數靠近臨界點時的長相是 $|v_a| \sim (\eta_c - \eta)^{\beta}$，**β ≈ 0.45**。

指數這種東西為什麼重要？因為它**跟細節無關**。換一種粒子、換一種抖法，只要對稱性一樣，那個 0.45 還是 0.45。這是物理學家最愛的那種結論：**一大堆看起來不同的系統，其實是同一個系統。**

## 密度也能扳動它

臨界點不是只有雜訊說了算。把 `boxScale` 縮小（等於把同樣多的粒子塞進更小的空間、密度變高），再跑一次掃描。

<button class="try" data-preset='{"boxScale":0.6,"eta":2.6}'>擠密一點</button>　<button class="try" data-preset='{"boxScale":1.8,"eta":2.6}'>攤稀一點</button>

密度高的時候，同樣的雜訊撐得住秩序；密度低的時候，一點雜訊就垮。

道理不難：**密度高＝鄰居多＝平均的樣本數多＝隨機誤差被平均掉**。這跟第 13 課「叛徒佔比多少會被帶走」是同一條數學骨架——**多數決的抗噪能力，取決於你數了多少人。**

## 這個模型錯在哪（很重要）

1995 年那篇說這是**連續**相變：秩序像滑坡一樣降下去。後來大家把電腦換好一點、把場地開大一百倍，發現不對——

在夠大的系統裡，這其實是**不連續（一階）相變**：臨界點附近會冒出一種東西叫**行進帶（traveling band）**，一條又密又整齊的隊伍在一片稀疏的亂流裡橫著跑，兩個相共存。

Vicsek 當年沒看到，不是算錯，是**場地太小**——箱子比行進帶的波長還短，那個結構根本擠不進去。

你手上這個模擬也一樣小。所以請這樣理解眼前的畫面：**它演示的是相變這回事，不是相變的最終定論。** 有限的箱子會給你有限的真相，這句話在做模擬時值得刻在牆上。

<button class="try" data-preset='{"count":1000,"boxScale":1.6,"eta":2.8,"trails":true}'>把粒子加到 1000、場開大、停在臨界點附近</button>

這個設定下，運氣好的話你會看到密集的帶狀結構在畫面上遊走。那就是行進帶的影子。

## 這一課要帶走的

> **群體的整齊度不是連續刻度，是有門檻的。門檻兩側是兩種東西，中間沒有折衷。**

這代表：一個群體系統「表現正常」不保證它安全——**它可能就站在臨界點旁邊，再一點雜訊就整個翻過去。** 你要知道的不是「現在整不整齊」，是「離門檻還有多遠」。
